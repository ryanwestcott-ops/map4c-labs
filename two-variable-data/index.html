One variable or two?

First name the subject: the person or thing the data is about. Then count how many facts are recorded about each subject.

One-variable

One fact per subject.

the number of TVs in each household

Two-variable

Two facts per subject, kept together as a pair.

the number of TVs and phones in each household

Watch out: frequency is not a variable. A bar graph of "how many households own 2 TVs" is still one-variable data: it counts subjects.

Independent and dependent variables

Independent (x-axis)

The variable we think affects the other, or that we know or control first.

Dependent (y-axis)

The variable that responds. It may depend on the other one.

Independent (x)Dependent (y)
Hours studiedTest mark
Age of a carPrice
Daily high temperatureIce cream cones sold

Ask: which one could change the other? If neither does (like marks in two courses), either axis is fine.

Describing a scatter plot

Each point is one subject, placed using its pair of values.

Strong: points lie close to a line. Weak: spread out but still leaning one way. Outlier: a point far from the pattern. A scatter plot shows that two variables are related; it does not prove one causes the other.

Posing questions

One-variable questions use one variable: "What is the most common age?" "How many teens are active 10+ hours a week?"

Two-variable questions ask how two variables are related: "Do older teens get less activity?" "Does more salt go with higher blood pressure?"
