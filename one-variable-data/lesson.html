Lesson: One-Variable Data

Learning Goals

By the end of this lesson I can:

  • tell the difference between one-variable and two-variable data
  • classify data as categorical, discrete, or continuous
  • organize data in a tally chart and a frequency table
  • choose and draw a suitable graph (bar graph, dot plot, or histogram) and explain my choice
  • write descriptive statements and pose questions that one-variable data can answer

One-variable data: one fact (variable) is recorded about each person or thing. Example: the number of siblings each student has.
Two-variable data: two facts are recorded about each one, to see how they are related. Example: each student's height and shoe size. (We study this later.)

Part 3: Drawing Dot Plots and Histograms 15 min

Graph checklist: title  ·  both axes labelled (with units)  ·  even scale starting at 0  ·  accurate dots or bars  ·  gaps for a bar graph, no gaps for a histogram

Example 1: Dot Plot. Twenty students reported their number of siblings:

0, 1, 1, 2, 1, 3, 0, 2, 1, 1, 4, 2, 0, 1, 2, 1, 3, 1, 0, 2

  1. Draw a number line from the smallest to the largest value (0 to 4).
  2. Place one dot above the value for each data point. Stack repeated values, one dot per square.
